## Purpose

WebLLMによるクライアントサイドAI修正提案生成の動作仕様を定義する。SmolLM2-1.7Bモデル向けに最適化されたプロンプトと推論パラメータを規定。

## ADDED Requirements

### Requirement: 推論パラメータの制約

システムはWebLLM推論時に以下のパラメータ制約を適用しなければならない（SHALL）：
- `max_tokens`: 512以下（提案リスト出力に十分、過剰生成防止）
- `temperature`: 0.2〜0.3（JSON構造出力の一貫性確保）
- ストップシーケンス: JSON終了を検出可能な場合は適用

#### Scenario: 短い入力テキストで高速推論
- **WHEN** 100文字以下の翻訳テキストペアが入力される
- **THEN** 推論は30秒以内に完了し、有効なJSON出力を返す

#### Scenario: 長い入力テキストで適切な時間内に完了
- **WHEN** 500文字程度の翻訳テキストペアが入力される
- **THEN** 推論は60秒以内に完了し、有効なJSON出力を返す

### Requirement: プロンプトの簡潔性

システムプロンプトは以下の条件を満たさなければならない（SHALL）：
- 500トークン以下の総プロンプト長（システム + few-shot + ユーザー入力前）
- JSON-only出力の明示的指示
- 説明文や思考過程の出力を禁止する指示

#### Scenario: JSON-only出力
- **WHEN** 任意の翻訳テキストペアで推論を実行する
- **THEN** 出力は`{"指摘": [...], "全体講評": "..."}`形式のJSONのみを含む

#### Scenario: 余分なテキストなし
- **WHEN** 推論が完了する
- **THEN** 出力にJSON以外のテキスト（説明、前置き、思考過程）を含まない

### Requirement: パース失敗時のフェイルファスト

JSONパースが失敗した場合、システムは以下を行わなければならない（SHALL）：
- 無限リトライを行わない（リトライは最大1回まで）
- ユーザーに明確なエラーメッセージを表示
- 空の提案リストと説明的なoverallCommentを返す

#### Scenario: 不正なJSON出力
- **WHEN** モデル出力がJSON形式でない
- **THEN** 空の提案リストと「AIの応答からJSONを抽出できませんでした」というoverallCommentを返す

#### Scenario: パース可能だが構造が不正
- **WHEN** モデル出力がJSONだが期待する構造でない
- **THEN** 抽出可能な部分のみを返し、欠落フィールドはデフォルト値を使用

### Requirement: タイムアウト保護

推論フェーズのタイムアウトは以下を満たさなければならない（SHALL）：
- 推論タイムアウト: 2分（現行維持、パラメータ最適化で実効時間は短縮）
- タイムアウト時は明確なエラーメッセージを表示
- 診断ハートビート（5秒間隔）は維持

#### Scenario: タイムアウト発生
- **WHEN** 推論が2分以内に完了しない
- **THEN** タイムアウトエラーを表示し、処理を中断する
